# Установщик «Визуализация данных»

Приложение остаётся **unpackaged WinUI 3**, поэтому одинаково запускается из
Visual Studio и напрямую как `DataVisualization.exe`. Для распространения
используется self-contained publish и Inno Setup 6.

## Сборка

Из корня репозитория:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Installer.ps1
```

Скрипт выполняет `dotnet publish` для `Release|x64`, собирает установщик,
выводит его SHA-256 и создаёт готовый descriptor обновления. Результат:

```text
installer\Output\DataVisualization-Setup-<version>.exe
installer\Output\data-visualization-version.txt
```

Версия берётся из свойства `Version` в
`AMK-Data-Visualization\AMK-Data-Visualization.csproj`; дублировать её в
скрипте установщика не требуется.

Перед компиляцией setup скрипт переносит из изолированного build-output
созданные WinUI-файлы `DataVisualization.pri` и `*.xbf` в publish-каталог.
Затем он проверяет EXE, runtime, PRI и XBF каждого окна. При неполном комплекте
сборка завершается ошибкой, поэтому установщик с неработающим XAML не создаётся.

## Поведение установки

- требуется подтверждение UAC;
- приложение устанавливается в `Program Files\Визуализация данных` и доступно
  всем пользователям компьютера;
- запись создаётся в «Параметры → Приложения → Установленные приложения»;
- пользователь может независимо выбрать общий ярлык в меню «Пуск» и на
  рабочем столе;
- повторный запуск setup обновляет существующую установку благодаря стабильному
  `AppId`;
- удаление выполняется стандартным Inno Setup uninstaller.

Неработающая сборка `0.1.0` не может получить обновление автоматически, потому
что завершается до запуска update-service. Для исправления достаточно вручную
запустить setup `0.1.1` поверх существующей установки; предварительное удаление
не требуется.

## Публикация обновления

Новый продукт использует отдельный каталог, чтобы не пересекаться с обновлениями
legacy-приложения:

```text
https://ivanbohg.beget.tech/FilesForProgramVisualisation/DataVisualization/
```

В этот каталог загружаются установщик и сгенерированный рядом с ним
`data-visualization-version.txt`:

```text
0.1.1
DataVisualization-Setup-0.1.1.exe
<необязательный SHA-256 установщика>
```

Первые две строки обязательны. Третья строка настоятельно рекомендуется: если
она присутствует, приложение проверяет SHA-256 до запуска setup. Пример без
контрольной суммы находится в
`update-feed\data-visualization-version.txt.example`.

При старте приложение через три секунды выполняет тихую проверку. Ошибки сети и
отсутствие новой версии не мешают работе. Если версия новее, пользователь
подтверждает загрузку; затем запускается подписанный/доверенный установщик с UAC,
приложение закрывается и стартует снова после обновления.

## Перед публичным распространением

Установщик и `DataVisualization.exe` следует подписать code-signing
сертификатом. Без подписи Windows SmartScreen может показывать предупреждение,
даже если SHA-256 и HTTPS корректны.
