# AMK Data Visualization

Актуальное состояние: **22 июля 2026 года**.

`AMK-Data-Visualization` — модульное приложение WinUI 3 / .NET 10 для чтения,
отображения и обработки данных геофизических приборов. Пользовательское имя
приложения — **«Визуализация данных»**, исполняемый файл —
`DataVisualization.exe`.

Проект переносит поведение Win32/C++ приложения
`C:\Users\Admin\Desktop\Amk-Horizon-New-Chart`. Старый проект остаётся
источником истины по бинарным форматам, расчётам и пользовательским сценариям до
завершения ручной parity-проверки.

## Реализованный функционал

### Файлы и данные

- чтение `.bin`, `.biv` и `.DEV` с преобразованием в canonical
  `GpToolData`;
- поддержка физических кадров 240 байт и `.DEV`-кадров 251 байт с payload
  offset 11;
- metadata/capabilities, semantic access-view и repository-состояние;
- экспорт выбранного диапазона в canonical `.bin`;
- вырезание диапазона из текущего файла или сохранение копии без диапазона с
  сохранением исходного физического формата.

### Графики

- один или два графика с независимыми конфигурациями и viewport-состояниями;
- Graph 2 в связанном режиме или с отдельным файлом;
- несколько кривых, одна или две Y-оси, X по номеру кадра или температуре;
- legacy-совместимые пресеты, легенды, сетка, nice-step и числовой формат;
- немодальное окно «Схема прибора» для Graph 1 и Graph 2;
- capability-aware выбор T1–T5, R1/R2 и молчащих каналов;
- диапазон X из полей, drag-zoom, пошаговый undo и reset;
- горизонтальная и вертикальная прокрутка увеличенного участка;
- автоматическая подгонка обеих Y-осей под новый видимый X-участок при
  горизонтальной прокрутке;
- режим `Поток`: последние N записей, следование за live-данными, Y-only zoom
  и вертикальная прокрутка;
- автоматический 5%-й отступ Y-диапазона от экстремумов.

### Прибор и метрология

- поиск COM-портов, 125000/8N1, polling, CRC16 и автоматическое
  переподключение;
- обычный length-framed transport и fixed-length transport `LOOP_NEXT` для
  `Картограф LWD 4tx`;
- чтение кадра, сигнатуры и метрологии, запись метрологии, selected key и
  автокалибровка воздуха в поддерживаемых transport-ветках;
- запись live-кадров в новый canonical `.bin` и дозапись существующего файла;
- папка записи по умолчанию `Desktop\AMK_Data`; другой выбранный путь хранится
  в `%LOCALAPPDATA%\AMK-Data-Visualization\connection-settings.json`;
- legacy-совместимый журнал обмена с обычными и raw-записями, расшифровкой
  `GP_TOOL_DATA`, идентификацией зонда и отдельными файлами сессий в
  `%LOCALAPPDATA%\AMK-Data-Visualization\Logs`;
- интерфейс хранит последние 300 элементов единым потоком; на диске остаются
  три последние сессии размером до 32 МБ каждая, а самая старая удаляется при
  создании четвёртой; запись выполняется вне потоков COM и UI;
- окно «Подключение к прибору»;
- окно «МЕТРОЛОГИЯ», 240-байтовые метрологические файлы и вычисления
  `FromComputer`;
- матрицы симметризации 3/4/5Tx, AIR-поправка, `SIGNAL` и обратный расчёт УЭС;
- `Картограф LWD 4tx` распознаётся по типу и числу передатчиков независимо от
  модификации;
- амплитуды этой ветки нормализуются из Q12 в общий LWD-контракт коэффициентом
  `1 / 4096`, при этом сырые canonical-кадры не изменяются.

### Поставка и обновление

- кодовая версия приложения: `0.1.2`; единственный источник версии — свойство
  `Version` в `.csproj`;
- unpackaged/self-contained `Release x64`;
- all-users установщик Inno Setup: Program Files, «Установленные приложения»,
  опциональные общие ярлыки меню «Пуск» и рабочего стола;
- единая иконка приложения, окон, EXE, ярлыков и установщика;
- ручная и фоновая проверка обновлений через отдельный descriptor нового
  приложения в рабочем legacy HTTP-каталоге;
- проверка имени файла, MZ-сигнатуры, размера и необязательного SHA-256 перед
  запуском обновления;
- сборка установщика проверяет наличие `DataVisualization.pri`, ключевых WinUI
  `*.xbf`, EXE и runtime-зависимостей и не создаёт заведомо неполный setup.

Setup `0.1.2` и descriptor с SHA-256 были успешно сформированы, однако после
этой сборки в исходники добавлены новые UI-функции. Поэтому существующий
`DataVisualization-Setup-0.1.2.exe` не является сборкой текущего дерева:
следующую публикацию нужно делать с новым номером версии и повторной упаковкой.

### Заметки на графике

- заметки хранятся рядом с активным файлом данных в append-only sidecar
  `<data-file>.notes.jsonl`; для COM-режима sidecar создаётся только при
  включённой активной записи;
- клик по графику устанавливает красное перекрестие и заполняет координаты
  курсора, кнопка `⌖` сбрасывает перекрестие и координаты;
- правый клик позволяет записать позицию перекрестия как начальную или конечную
  границу X либо создать заметку;
- маркеры показываются только для совпадающей конфигурации оси X и включённых
  кривых с их группами осей Y; пресет в ключ сопоставления не входит;
- клик по маркеру позволяет изменить или удалить заметку, а журнал заметок
  поддерживает обновление текста и восстановление сохранённой конфигурации;
- кнопка «Заметки» сразу открывает журнал без промежуточного выпадающего меню;
- для Graph 2 в режиме отдельного файла создание и отображение заметок
  отключено, как в legacy-приложении.

### Окна и навигация

- окна подключения, конструктора файлов, журнала заметок, логов и метрологии являются
  немодальными, отображаются в панели задач и наследуют иконку приложения;
- при первом и повторном открытии эти окна центрируются относительно главного
  окна и корректно восстанавливаются после сворачивания;
- кнопки открытия файла Graph 2 и папки в статусной строке используют системную
  иконку папки Windows;
- кнопка в статусной строке открывает папку обычного файла или папку COM-записи;
  при двух независимых файлах предлагается выбрать Graph 1 или Graph 2.

## Реализовано частично

- сохранение и вырезание диапазона работает для Graph 1, включая добавление выбранного
  участка или файла без выбранного участка к существующему canonical `.bin`;
- конструктор файлов объединяет совместимые `.bin/.biv/.DEV` в canonical `.bin`, позволяет
  менять порядок сегментов и повторно открывать/пересохранять сборку;
- описание сегментов хранится в `%LOCALAPPDATA%\AMK-Data-Visualization\segments`, переносится
  при вырезании диапазона и используется для пунктирных границ на графиках;
- пункт «Документация» остаётся заглушкой;
- `AMK.DataVisualization.Reporting` является пустым архитектурным контейнером;
- LOD/downsampling и отдельно формализованная общая geometry-модель ещё не
  реализованы; notes/crosshair используют текущую геометрию `LineChartControl`.

## Что ещё требует проверки

- полный parity всех кривых и пресетов на контрольных `.bin/.biv/.DEV`;
- численное сравнение `FromSonde` и `FromComputer` со старым приложением;
- полный цикл COM reconnect, чтения/записи метрологии и записи файла на
  физическом приборе;
- range export/cut на всех форматах;
- удаление и обновление между двумя опубликованными подписанными версиями;
- производительность на больших файлах после реализации LOD/cache.

Владелец подтвердил поведение zoom/scroll/автомасштабирования, заметок,
кнопок папок и вспомогательных окон. Это не заменяет перечисленные выше
parity- и release-проверки.

## Архитектура

| Проект | Ответственность |
| --- | --- |
| `AMK-Data-Visualization` | WinUI shell, окна и orchestration |
| `AMK.DataVisualization.Core` | binary layout, domain models, adapters, access-view |
| `AMK.DataVisualization.IO` | чтение файлов, repository, range export |
| `AMK.DataVisualization.Hardware` | COM transport, polling, recording и диагностика |
| `AMK.DataVisualization.Charting` | конфигурации кривых и расчёт series |
| `AMK.DataVisualization.Metrology` | метрологическое состояние и расчёты |
| `AMK.DataVisualization.Reporting` | будущие отчёты и экспорт |

## Сборка

Требуются Windows и .NET 10 SDK.

```powershell
dotnet build .\AMK-Data-Visualization.slnx -c Debug -p:Platform=x64 --no-restore
```

Сборка установщика без запуска приложения:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Installer.ps1
```

Автоматизированных тестовых проектов в решении нет. Сборка подтверждает только
компиляцию; runtime и parity проверяются отдельно.
