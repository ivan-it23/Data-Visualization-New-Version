# AMK Data Visualization

Приложение для чтения, отображения и обработки данных геофизических приборов
индукционного каротажа производства ООО НПФ «АМК ГОРИЗОНТ».

- пользовательское имя — **«Визуализация данных»**;
- исполняемый файл — `DataVisualization.exe`;
- версия кода — `0.1.8` (единственный источник — свойство `Version` в
  `AMK-Data-Visualization/AMK-Data-Visualization.csproj`).

Приложение работает и с файлами, записанными ранее, и с прибором в реальном
времени через COM-порт.

## Источник истины

**Поведение прибора описывают его прошивки.** В корне проекта лежат два файла:

```text
main_LWD_1DDS      — прошивка приборов LWD
main_AUTO_5Tx.txt  — прошивка автономных приборов
```

Любой вопрос о составе команд, формате пакетов, содержимом квитанций, единицах
величин и расчётах на стороне прибора решается чтением этих файлов. Догадки,
аналогии и «скорее всего так» недопустимы: неверно понятый контракт даёт
внешне правдоподобный, но неверный график, и обнаруживается это уже на объекте.

Если нужного ответа в прошивках нет, это фиксируется как открытый вопрос, а не
заполняется предположением.

## Возможности

Подробное описание каждой функции — в [`docs/FUNCTIONALITY.md`](docs/FUNCTIONALITY.md).

### Файлы данных

- чтение `.bin`, `.biv` и `.DEV` с приведением к единому 240-байтовому кадру;
- устойчивость к неполным данным: оборванный последний кадр и отдельные
  нечитаемые кадры пропускаются, пользователь получает сводку;
- сохранение выбранного диапазона, вырезание диапазона, сохранение копии без
  диапазона и дозапись в существующий файл;
- конструктор файлов: объединение совместимых файлов в один с сохранением
  границ исходных сегментов.

### Графики

- один или два графика с независимыми конфигурациями и состояниями просмотра;
- второй график в связанном режиме или с собственным файлом;
- несколько кривых, одна или две оси Y, ось X по номеру кадра или по
  температуре;
- быстрые пресеты, схема прибора, поканальный выбор передатчиков, приёмников и
  молчащих каналов;
- настройка вывода кривых прямо на графике без открытия отдельного окна;
- масштабирование выделением, пошаговая отмена, отдельный zoom каждой оси Y,
  прокрутка и автоматическая подгонка диапазона;
- режим `Поток` для работы с живыми данными.

### Заметки

- заметки хранятся рядом с файлом данных и переживают перезапуск;
- перекрестие по клику, координаты обеих осей Y, создание заметки из
  контекстного меню, маркеры на графике и журнал заметок.

### Работа с прибором

- поиск COM-портов, обмен на 125000 бод, опрос, контроль CRC и автоматическое
  переподключение;
- чтение кадров и метрологии, запись метрологии, автокалибровка нулей воздуха;
- поддержка двух транспортов обмена, включая режим `Картограф LWD 4tx`;
- запись живых кадров в новый файл или дозапись существующего;
- журнал обмена с прибором с расшифровкой кадров и файлами сессий.

### Метрология и расчёты

- окно метрологии, чтение и запись параметров прибора, работа с
  240-байтовыми файлами метрологии;
- воздушная поправка, матрицы симметризации для 3, 4 и 5 передатчиков,
  обратный расчёт УЭС и симметризованные фазы;
- режим расчёта на стороне приложения доступен только после чтения метрологии.

### Загрузка файлов в базу учёта приборов

- загрузка метрологии, калибровки, термопрофиля и КИС прямо из приложения в
  карточку прибора на сайте учёта;
- прибор определяется автоматически по серийному номеру из метрологии;
- раздел «Метрология» или «Калибровка» выбирается по факту выполнения
  автокалибровки, а не вручную;
- защита от повторной загрузки одного и того же файла;
- доступ по токену, который пользователь создаёт в своём профиле на сайте.

### Оформление и поставка

- фиксированная светлая тема и постоянная палитра акцента независимо от
  настроек Windows;
- пользовательский масштаб окон, сохраняемый между сессиями;
- установщик для всех пользователей компьютера и проверка обновлений.

## Архитектура

| Проект | Ответственность |
| --- | --- |
| `AMK-Data-Visualization` | окна, оркестрация, взаимодействие с пользователем |
| `AMK.DataVisualization.Core` | двоичные структуры, модели предметной области, возможности приборов |
| `AMK.DataVisualization.IO` | чтение файлов, хранилище кадров, операции с диапазонами |
| `AMK.DataVisualization.Hardware` | COM-обмен, опрос, запись, диагностика |
| `AMK.DataVisualization.Charting` | конфигурации кривых, расчёт серий, заметки |
| `AMK.DataVisualization.Metrology` | состояние метрологии и метрологические расчёты |
| `AMK.DataVisualization.DeviceRegistry` | обмен с базой учёта приборов |
| `AMK.DataVisualization.Reporting` | зарезервировано под отчёты, реализации нет |

Разбор двоичных данных и расчётные формулы находятся в библиотеках; окна их не
дублируют. Подробнее — [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Сборка

Требуются Windows и .NET 10 SDK.

```bash
dotnet build ./AMK-Data-Visualization.slnx -c Debug -p:Platform=x64 --no-restore
```

Сборка установщика:

```bash
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./scripts/Build-Installer.ps1
```

Автоматизированных тестов в решении нет: успешная сборка подтверждает только
компиляцию. Работа с прибором и точность расчётов проверяются вручную.

## Состояние проверки

Подтверждено на физическом приборе: приём кадров, запись файла и чтение
метрологии в режиме `Картограф LWD 4tx`, определение транспорта обмена.

Подтверждено в работе: загрузка файлов в базу учёта приборов — создание токена,
проверка связи, определение прибора по серийному номеру, выбор прибора из списка
при отсутствии карточки и сохранение файла в карточке.

Не подтверждено и требует ручной проверки:

- автокалибровка нулей воздуха (обе ветки транспорта);
- запись метрологии в length-framed ветке и команда передачи выбранного ключа;
- полный цикл переподключения при обрыве связи;
- численное сравнение расчёта на стороне прибора и на стороне приложения на
  одних и тех же данных.

Не реализовано: прореживание данных и кэш для больших файлов, отчёты, печать и
экспорт, встроенная документация внутри приложения, подпись кода.
